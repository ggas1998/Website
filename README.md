# Researcher Site v0.1

A zero-dependency static personal research website.

## Local preview

Open `index.html` directly in a browser, or use any simple local HTTP server.

## Free deployment options

### GitHub Pages
1. Create a free GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Enable GitHub Pages in repository settings.

### Vercel
1. Create a free Vercel account.
2. Import the GitHub repository.
3. Deploy as a static site.
4. For private preview access, use Vercel's available deployment protection options for your account/plan.

## Customize

Replace placeholder project titles, publication entries, email address, and profile links in `index.html`.
